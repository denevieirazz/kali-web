# Project Rules

- **Autonomia Total**: Sempre execute e resolva as tarefas diretamente. Se for possível executar o comando, criar os arquivos ou realizar a ação, FAÇA diretamente sem mandar o usuário fazer.
- **Sincronização Contínua com GitHub**: Sempre que qualquer arquivo ou código for modificado ou criado, atualize o README.md e envie as alterações (commit + push) automaticamente para o GitHub (`origin/main`) sem precisar de confirmação.
