# Instaladores de Patches Históricos

Status: **arquivado / não executar**.

Estes scripts `.cmd` e `.ps1` pertenciam a patches manuais e hotfixes intermediários aplicados durante o desenvolvimento inicial do CloudOS-Unified. Todas as correções e componentes (Settings, ContextMenu, CloudOSFiles, StartMenu, bridge nativa) já foram integrados diretamente no código-fonte em `frontend/src/` e validados por suítes de testes automatizados e regressão visual Playwright.

Os scripts e seus payloads foram movidos para esta quarentena exclusivamente para histórico e auditoria, não devendo ser executados novamente no ambiente ativo.
